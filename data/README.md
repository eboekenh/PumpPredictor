# Data Directory

Place the DrivenData competition files here:

- `training_set_values.csv` — Training features (59,400 rows × 40 columns)
- `training_set_labels.csv` — Training labels (status_group)
- `test_set_values.csv` — Test features for submission

Download from: https://www.drivendata.org/competitions/7/pump-it-up-data-mining-the-water-table/data/

**Note:** Data files are not committed to this repository (see `.gitignore`).
